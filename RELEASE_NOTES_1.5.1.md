# School App 1.5.1 (final stable)

## UI
Layout and styles of v1.4.8 (cards, header, forms, purple theme).

## Features
- First-run setup: school name + logo (saved permanently; editable by admin)
- Session persists in localStorage until user logout
- Admin: add teachers, assign teacher→class→subject
- Teacher panel: only assigned classes/subjects
- Roles: admin/teacher edit; manager/staff view + Excel export
- Jalali date from 1405/08/20 with 3 dropdowns (year/month/day)
- Keyboard: page scrolls above keyboard
- Eitaa absence messages with full context
- Optional local/VPS sync server (port 3847)

## Install
1. Uninstall previous APK
2. Install SchoolApp-v1.5.1-release.apk
3. Complete setup (name + logo)
4. Login admin / admin123 and change password
