# سرور محلی سامانه بشری

## ویندوز (پیشنهادی)

فایل `Boshra-School-Server.exe` را اجرا کنید. این برنامه:

1. اگر Node.js نصب نباشد، نسخه همراه را دانلود می‌کند
2. وابستگی‌ها (express, cors) را نصب می‌کند
3. سرور را روی پورت **3847** راه می‌اندازی می‌کند
4. آدرسی که باید در اپ وارد کنید را نمایش می‌دهد:
   - روی همان کامپیوتر: `http://127.0.0.1:3847`
   - روی موبایل (همان وای‌فای): `http://IP-کامپیوتر:3847`

ورود پیش‌فرض: `admin` / `admin123`

پنجره را نبندید؛ با بستن پنجره سرور متوقف می‌شود.

## دستی (هر سیستم‌عامل)

```bash
cd server
npm install
npm start
```

پورت پیش‌فرض: **3847**
