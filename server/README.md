# سرور محلی بشری ۱.۶.۲

## ویندوز
1. فایل `install-and-run.bat` را اجرا کنید.
2. اگر Node.js نباشد، با winget نصب می‌شود.
3. مرورگر صفحه وضعیت (تم بنفش) را باز می‌کند و لینک‌های LAN را نشان می‌دهد.
4. در گوشی‌ها همان لینک را در مرورگر یا فیلد «آدرس سرور» صفحه ورود وارد کنید.

## دستی
```
npm install
npm start
```
