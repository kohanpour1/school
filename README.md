# مدیریت کلاس بشری ۱.۶.۴

## پرداخت درون‌برنامه‌ای (کافه‌بازار / Poolakey)
- برای ورود به **بخش ادمین** یک‌بار پرداخت لازم است (بدون اشتراک).
- شناسه محصول (SKU): `admin_unlock` — همین نام را در پنل بازار بسازید (محصول غیرمصرفی).
- کلید RSA در `MainActivity.kt` قرار دارد.
- معلمان نیازی به پرداخت ندارند.

## سایر امکانات
- ارزیابی: کلاسی / مستمر / آزمون (سقف ۵، ۱۰، ۲۰) + معادل از ۲۰
- حضور، گزارش، پیام ایتا، سرور محلی، …

## حساب
admin / admin123 (پس از خرید یک‌باره روی دستگاه)

## تست پرداخت
برنامه **بازار** باید روی دستگاه نصب و کاربر وارد شده باشد.
