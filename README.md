# سامانه مدیریت مدرسه بشری

مؤسسه آموزشی غیر دولتی بشری — حضور و غیاب، نمره، اعلان ایتا، همگام‌سازی چند دستگاه

**نسخه فعلی:** `1.4.3`

## قابلیت‌ها

- نقش‌ها: مدیر، معاون، معلم
- ثبت حضور/غیبت با اعلان فوری ایتا به والدین (نام کامل + تاریخ)
- نمره عددی، معدل، کسر غیبت، مثبت/منفی
- سال تحصیلی و تاریخ جلالی به‌صورت select (نه متن آزاد)
- عکس دانش‌آموز، خروجی اکسل، جلسات
- آفلاین‌فرست + همگام‌سازی با سرور
- تم بنفش، RTL، فونت وزیرمتن، لوگو

## ساختار پروژه

```
app/                 اپ اندروید (WebView + assets)
server/              سرور Node.js برای همگام‌سازی
.github/workflows/   بیلد خودکار APK
```

## راه‌اندازی سرور محلی (همگام‌سازی چند موبایل)

### پیش‌نیاز
- Node.js نسخه ۱۸ یا بالاتر

### نصب و اجرا

```bash
cd server
npm install
npm start
```

سرور روی پورت **۳۸۴۷** اجرا می‌شود:

```
http://localhost:3847
```

### حساب‌های پیش‌فرض

| کاربر    | رمز       | نقش          |
|----------|-----------|--------------|
| admin    | admin123  | مدیر سامانه  |
| modir    | modir123  | مدیر         |
| moaven   | m123      | معاون        |
| teacher1 | t123      | معلم         |

### اتصال موبایل / اپ به سرور

1. سرور را روی کامپیوتر اجرا کنید.
2. IP کامپیوتر در شبکه محلی را پیدا کنید (مثلاً `192.168.1.10`).
3. در صفحه ورود اپ، آدرس سرور را وارد کنید:
   ```
   http://192.168.1.10:3847
   ```
4. با همان حساب روی چند دستگاه وارد شوید → داده‌ها همگام می‌شوند.

### استقرار روی اینترنت (اختیاری)

- Render / Railway / VPS: دستور `node server/server.js` با متغیر محیطی `PORT`
- بعد از استقرار، آدرس عمومی را در صفحه ورود اپ وارد کنید.

## نکات مهم

- اپ به‌صورت offline-first کار می‌کند؛ بدون سرور هم قابل استفاده است.
- اعلان غیبت فقط وقتی ارسال می‌شود که برای دانش‌آموز **آیدی عددی ایتا والدین** ثبت شده باشد.
- تاریخ و سال تحصیلی از لیست انتخاب می‌شوند (دیگر متن آزاد نیست).
- اگر صفحه روی «در حال بارگذاری...» ماند، از APK نسخه `v1.4.3-final` استفاده کنید (دارای app.js کامل).
