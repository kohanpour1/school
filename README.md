# مدیریت کلاس بشری — نسخه ۱.۶.۰

نسخه کامل هم‌سطح پیش‌نمایش. فقط `index.html` را باز کنید.

- راه‌اندازی نام و لوگوی مدرسه، سپس ورود
- حساب مدیر: `admin` / `admin123`
- ادمین: پایه، کلاس، درس، معلم، تخصیص
- معلم فقط کلاس و درس تخصیص‌یافته را می‌بیند
- نمرات پویا با سقف دلخواه و تبدیل به ۲۰
- سال تحصیلی و نوبت اول/دوم؛ گزارش CSV برای یک نوبت یا هر دو
- تاریخ شمسی از ۱ مهر ۱۴۰۵ با سه کشو
- توکن ایتا فقط داخل برنامه، بخش ادمین (در این مخزن نیست)
