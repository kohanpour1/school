# مدیریت کلاس بشری ۱.۶.۳

## امکانات
- ارزیابی: کلاسی / مستمر / آزمون با سقف ۵، ۱۰ یا ۲۰ + معادل‌سازی خودکار از ۲۰
- نمره پایانی: میانگین خودکار مستمر و آزمون (با مثبت/منفی)
- خانه: تعداد غایب هر کلاس
- حضور: دکمه‌های حاضر (سبز) / غایب (قرمز) + توضیح
- گزارش: دانلود و نمایش همزمان CSV
- ورود: فیلد آدرس سرور
- پیام ایتا: همه پایه‌ها / یک پایه / چند کلاس / دانش‌آموز با جستجو
- آپلود لوگو و عکس دانش‌آموز
- فاصله امن نوار وضعیت و اسکرول کیبورد
- توکن ایتا فقط در ادمین (از پنل eitaayar)
