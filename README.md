# مدیریت کلاس بشری ۱.۶.۲

## امکانات جدید
- خانه: تعداد غایب هر کلاس
- حضور: دکمه‌های حاضر (سبز) / غایب (قرمز) + توضیح
- گزارش: دانلود و نمایش همزمان CSV/Excel
- ورود: فیلد آدرس سرور
- پیام ایتا: همه پایه‌ها / یک پایه / چند کلاس / دانش‌آموز با جستجو
- آپلود لوگو و عکس دانش‌آموز
- فاصله امن نوار وضعیت و اسکرول با کیبورد
