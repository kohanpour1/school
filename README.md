# مدیریت کلاس بشری ۱.۶.۲

## امکانات
- خانه: تعداد غایب هر کلاس در صورت وجود
- حضور: دو دکمه حاضر (سبز) / غایب (قرمز) + فیلد توضیح برای هر دانش‌آموز؛ اسامی طولانی بدون مشکل
- گزارش: با فشردن دانلود هم ذخیره می‌شود هم پیش‌نمایش نمایش داده می‌شود (CSV با BOM برای اکسل)
- ورود: نام کاربری + آدرس سرور اختیاری
- پیام ایتا: همه پایه‌ها / یک پایه / چند کلاس / دانش‌آموز(ان) با جستجو و چندانتخابی
- آپلود لوگو مدرسه و عکس آواتار هر دانش‌آموز
- فاصله امن از نوار وضعیت و اسکرول خودکار هنگام باز شدن کیبورد

## حساب پیش‌فرض
`admin` / `admin123`

## سرور محلی (چند گوشی روی یک شبکه)
پوشه `server/` را روی ویندوز اجرا کنید (`install-and-run.bat`).
پیش‌نیاز Node.js به‌صورت خودکار نصب می‌شود و صفحه وضعیت با تم برنامه باز می‌شود و لینک‌های LAN را نشان می‌دهد.

## بیلد
با push به `main` اکشن `Android Release Build` APK امضاشده را می‌سازد و در Release منتشر می‌کند.
