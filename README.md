# سامانه مدیریت مدرسه (عمومی)

اپ آفلاین‌اول برای هر مدرسه — روی سرور محلی یا مجازی.

## راه‌اندازی اولیه
1. نصب APK
2. اولین اجرا: نام مدرسه + لوگو + سال تحصیلی
3. ورود: `admin` / `admin123` (حتماً رمز را عوض کنید)
4. ادمین: تعریف کلاس، درس، دانش‌آموز، معلم و **تخصیص معلم به کلاس/درس**

## نقش‌ها
| نقش | دسترسی |
|------|--------|
| admin | کامل |
| teacher | فقط کلاس/درس‌های تخصیص‌شده — مشاهده و ویرایش |
| manager / staff | مشاهده + خروجی اکسل |

## سرور همگام‌سازی (اختیاری)
فایل `Boshra-School-Server.exe` یا `node server.js` — پورت پیش‌فرض **3847**
